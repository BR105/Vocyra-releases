# Vocyra

Soundboard gratuito para Windows: reproduce sonidos ilimitados en Discord, juegos y llamadas, con atajos de teclado globales.

## Descarga

Descarga **[Vocyra-portable.zip](https://github.com/BR105/Vocyra-releases/releases/latest/download/Vocyra-portable.zip)**, descomprímelo y la primera vez abre «Abrir Vocyra (primera vez).bat».

## Requisitos

- Windows 10 u 11.
- [VB-Cable](https://vb-audio.com/Cable/) (gratis). Vocyra puede instalarlo por ti desde Ajustes.

## Uso rápido

1. Abre `Vocyra.exe`.
2. En Discord (o el juego/app de llamadas) elige **CABLE Output** como micrófono.
3. En Vocyra → Ajustes, elige tu micrófono real. Tu voz y los sonidos llegan juntos.
